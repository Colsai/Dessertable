### Skills to Know About
- `/plan` — drafts an implementation plan before touching code. Used frequently here before feature work; lets you align on approach and catch edge cases early.
- `/resume` — picks up where a previous session left off. Useful when you've got a multi-step feature in flight and come back the next day.
- `/simplify` — reviews recently changed code for reuse, quality, and efficiency, then fixes any issues found. Good as a last pass before committing.
- `/batch` — runs a prompt across multiple inputs or files in one shot. Handy for repetitive transformations.
